# ROX Digital Agency

Create a brand-new website UI from scratch for **ROX Agency** (rox.ma), a developer-led digital agency based in Oujda, Morocco.

**Purpose:** Present website creation, SEO, and digital services to Moroccan businesses and convert visitors into project inquiries.

**Design and colors:**
- Bold, premium, modern, minimalist design.
- Primary accent: red (#E31B23).
- Dark mode: near-black backgrounds, white text, red accents.
- Light mode: white backgrounds, near-black text, red accents.
- Add a working light/dark theme toggle that updates the entire interface.
- Strong typography, clean spacing, subtle animations, responsive layouts, and Lucide icons.
- Avoid excessive gradients, glowing effects, generic agency templates, and unnecessary decoration.

**Homepage sections:** Navbar, hero, business challenges, services, website + SEO value proposition, pricing preview, four-step working process, FAQ, contact CTA, and footer.

**Services:** Professional website creation, SEO (including local SEO), Figma prototyping, WordPress/Elementor development, and shared hosting offered for the first year on eligible projects.

**Pricing reference:** Website + local SEO setup: 2,000–3,000 DH; ongoing SEO: 700–1,200 DH/month. Treat these as indicative ranges.

**Content:** Write natural, professional French for the Moroccan market. Emphasize practical business value rather than exaggerated promises. Never invent clients, testimonials, statistics, rankings, guarantees, contact details, or company credentials.

**Scope:** This is a lightweight UI prototype for visual reference. Build the homepage, reusable components, responsive design, and functional theme toggle. Use simple frontend-only interactions. No dashboards, authentication, database, complex backend, or unnecessary integrations. Do not waste effort on features unrelated to the visual presentation.

Create the actual working website, not a redesign brief, wireframe, or static description. Keep the implementation simple and compatible with Lovable's free usage limits.
